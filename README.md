# @u1f992/vivliostyle-index

A [unified](https://github.com/unifiedjs/unified) plugin for generating indexes in [Vivliostyle CLI](https://github.com/vivliostyle/vivliostyle-cli) builds.

The indexing rules are based on Fujita (2019) and the Japan Science and Technology Agency (n.d.).

The default output follows the index structure specified by the DAISY Consortium (n.d.) and identifies the index with the DPUB-ARIA `doc-index` role (Garrish and Siegman 2025). It extends the DAISY structure where the guidance does not address implementation requirements.
